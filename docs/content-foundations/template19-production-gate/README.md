# Template19 production-gate recipes
This importer-shaped catalog contains the exact 19 knowledge-point keys from the declined-import cohort. The 236 worked samples exhaust every satisfying parameter combination: 17 recipes have 12 instances and two have 16. Each sample retains the computed answer and each recipe supplies a rendered worked solution.

## Canonical sources
`drafts.json` is the reviewed authoring input; `sources.json` maps it to the existing unit catalogs. After running an older unit generator, run `python3 scripts/authoring/sync_template19_recipes.py`. The `--check` mode and `test_template19_sources.py` reject drift without a database or model. Superseded unit06 review snapshots retain their original body and digest for historical evidence.

## Preserved objectives
Ten recipes required content changes beyond contract propagation. Integer comparisons now combine a computed truth judgment and a typed ascending chain. Triangle classification covers 12 distinct similarity classes across acute, right, and obtuse cases. Radical tasks require isolation and substitution; the sign-check task returns the actual empty or singleton solution set. Percentage tasks distinguish finding a part from finding a percent. Unit prices compare both per-item prices. Equivalent ratios ask for a missing part and an equivalence judgment; ratio tables retain both common-volume counts and the stronger mix. Vertex-form parameters use a three-coordinate contract. Incline-angle tasks use 12 distinct rise/run ratios with certified one-decimal inverse-tangent answers, as the KP permits.

The remaining nine recipes retain their existing content and precise contracts. Logarithmic and exponential equation writers validate the base, exponent, and argument before selecting their bounded equation vocabulary. A solved value or a different equation is outside that vocabulary.

## Verification boundaries
Rust tests exercise the pure template gate, exhaustive samples, contract propagation, adversarial answers, triangle/angle materiality, and collisions against curriculum exemplars, diagnostics, and checked-in template catalogs. The worker tests and import evidence cover the separate production preflight and pending-only storage path. This catalog grants no approval or production import authorization.
