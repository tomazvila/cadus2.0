# Independent Teach approval evidence
All 735 Teach pages have source-bound independent offline approvals.

`evidence.tar.gz` preserves the 30 original review packets, 30 raw reviews, reconciliation, accepted repairs, final approval ledger, source snapshot, native gate receipts, and audit scripts. `index.json` binds every archived file and the archive itself by SHA-256.

Extract the archive into a separate audit directory to inspect or reproduce the review. These are historical review inputs and evidence; they are not additional authoring candidates. Source changes invalidate the affected approvals according to the ledger. Live serving approval and deployment remain separate operations.
