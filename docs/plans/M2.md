# M2 — Answer checker: grammar, normalization, exact arithmetic, oracle fuzz

Requirement IDs: V1, V2, V3, V4, D6, A3, C4, L2. Spec: `docs/reference/checker-1.0-spec.md`
(the 1.0 pipeline, its defects, the corpus statistics, the grammar proposal, the oracle).
Corpus: `crates/core/tests/fixtures/answers/corpus_1_0.jsonl` (3,492 answers of the 478
verifiable topics). Oracle: 1.0 `cadus_web.sympy_check.answers_equivalent` and
`dot_thousands_variant`, run with `/home/deploy/dev/cadus/.venv/bin/python`.

## Fixed decisions (orchestrator)

- All M2 code lives in `cadus-core` under `src/answer/` (R3). Allowed new deps: `num-bigint`,
  `num-rational`, `num-integer`, `num-traits` (pure arithmetic). The purity literal changes.
- No float in any equality decision (D6). Decimals become exact rationals. Radicals are
  canonicalized by squarefree factoring. Polynomials are sparse multivariate forms with
  rational coefficients. Function applications compare structurally on canonical arguments.
  `sin(x)^2 + cos(x)^2` is NOT equal to `1` in 2.0 — a documented narrowing of 1.0 (V1:
  no heuristic simplification).
- The grammar is spec §8.1 plus the `interval` production (`[a, b]`, `(a, b]`, `x <= a`,
  `a <= x <= b`). Out-of-grammar input on either side → `Verdict::Undecidable` (V2). The
  checker never panics and never raises: every failure is `Undecidable` or `false`.
- Verdict shape (C4): `Verdict { correct: bool, notation: bool }` or `Undecidable`. No
  `work_quality`, no error tags other than the `notation` flag.
- A3 change from 1.0: the checker returns `correct = false` for a wrong in-grammar answer
  (1.0 handed a wrong answer to the model). The 1.0 string-match rung that ran before the
  kind gate is NOT ported: `multi-step` and `proof` are always `Undecidable`.
- V4 tolerance carried over: outer `$…$`, trailing periods, whitespace collapse, casefold on
  the string rung, comma/space thousands on a full match, `^`→`**`, `\cdot`/`\times`/`·`/`×`,
  `÷`, `\left`/`\right`, the Unicode table (`π`, `τ`, `∞`, `−`, `–`, `≤`, `≥`, Greek, vulgar
  fractions, superscripts, `√`, `°` deleted). New in 2.0: `\frac{a}{b}`, `\sqrt{a}`, `^{n}`,
  trailing `%`, leading `x =`/`y =` prefix. The dot-thousands reading stays last and sets
  `notation` (1.0 `_DOT_GROUPS_RE` with the non-zero leading group; spec §7.2).
- L2: the whole corpus self-check (3,492 pairs) runs in under 1 s in a debug build; a
  single check is bounded by input length (4,000 chars, spec §7.9) and never by search.

## Revised after review (round 1, 2026-08-27)

Review round 1 raised 39 findings and confirmed 21 (`docs/reviews/M2-review-1.md`). The
orchestrator rulings changed the grammar and the checker in seven places. The decisions
above stand except where this section replaces them.

- **Mixed numbers with vulgar glyphs.** A digit run followed by a vulgar-fraction glyph is
  the mixed number: `2⅓` is 7/3 and `3½` is 7/2. The glyph on its own keeps the 1.0
  reading. A mixed number `a b/c` needs `0 < b < c` in plain digit runs, so `1 000/3` is
  Undecidable (findings #1, #7, #9).
- **Labels are `Assign`.** A leading `<var> =` on either side becomes
  `Assign(var, value)`, not a deleted prefix (findings #2, #10, #16).
- **The label tolerance is symmetric.** If one side carries a label and the other carries
  none, the label falls away and the two values compare. If both carry a label, the two
  names must be equal casefolded. An expected `x = 5` accepts a learner `5`, and an
  expected `5` accepts `x = 5`; `x = 4` against `y = 4` is false.
- **Times-`x` and times-`X`.** A spaced single `x` OR `X` between two numeric literals is
  multiplication: `6 x 10^3` and `6 X 10^3` are 6000, and `3 X 4` is 12. Every other `x`
  and `X` is the variable, so `X` alone and `2X` stay variables (finding #18).
- **A width-charged work bound.** `MAX_BITS` charges the width of every number the
  arithmetic builds, after every operation, and `content_normalize` runs inside the
  budget. Exceeding the bound is Undecidable. `MAX_STEPS` stays (findings #5, #11).
- **`ln` is `log`.** The two spellings are one function atom, the natural logarithm
  (finding #8).
- **`Atom::Exp`.** `exp(a)` is `e^(a)` for every argument, and the exponent law holds, so
  `1/e^x` equals `e^(-x)` (finding #19).

Two more items of the same round:

- **The bracket-free function argument** takes the whole juxtaposed chain of atoms with
  their powers, so `cos 2x` is `cos(2*x)` (findings #3, #4, #6). A percent binds to the
  number it follows, so `3 + 4%` is 3.04 (finding #17). A short run of unknown letters
  splits into single-letter variables, so `3xy^2` is `3*x*y**2`.
- **The oracle harness** runs every 1.0 call in a child process and terminates it on the
  deadline, so a timeout is `{"timeout": true}` and never a decided `false` (finding #21).

Measured after the fixes: the corpus splits into 3,227 parsed and 265 undecidable answers
(was 3,214 and 278). The generated oracle set holds 14,989 pairs, and class 3 agreement
with the live 1.0 checker is 14,037 of 14,037 (100.0000%).

These numbers supersede the "3,262" and "230" literals of the U1 and U3 acceptance rows
above. `crates/core/tests/answer_parse.rs` and `crates/core/tests/answer_oracle.rs` hold
them as literals, and `docs/reference/checker-1.0-spec.md` sections 8.2 and 8.3 carry the
measured split and the reason for the difference.

## Revised after review (round 2, 2026-08-27)

Review round 2 raised 20 findings and confirmed 17 (`docs/reviews/M2-review-2.md`). The
orchestrator rulings changed the parser, the canonicalizer, and the oracle harness. The
decisions above stand except where this section replaces them. Fix units: FIXM2d
(normalize and parse), FIXM2e (canon and harness), FIXM2f (fixtures and docs).

### The grammar (FIXM2d)

- **Mixed numbers, in every spelling.** A whole number followed by a fraction is the mixed
  number `whole + num/den` in all five spellings: `a b/c`, `a½`, `a ½`, `a\frac{b}{c}`, and
  `a \frac{b}{c}`. A negative whole part carries its sign over the whole value, so `-2 1/2`
  is -5/2. The rule has one place, and that place is the parser: `normalize` writes every
  vulgar glyph and every `\frac{b}{c}` of two digit runs as one literal-fraction token,
  spelled `⟦b/c⟧` with the marks U+27E6 and U+27E7, and `parse::read_mixed_number` applies
  the `0 < b < c` and plain-digit rules once. A number token in front of a fraction is a
  mixed number or the answer is undecidable; a token that no number precedes makes a
  product (findings #1, #2, #3, #5, #6, #7).
- **The argument chain runs through `*`.** The bracket-free function argument continues
  through an explicit `*` and through implicit multiplication. It stops at `/`, `+`, `-`,
  `,`, `)`, `=`, `<`, and `>`. So `cos 2*x` is `cos(2*x)` and `sqrt 2/2` is `sqrt(2)/2`
  (findings #4, #15).
- **`\sqrt` takes a product sign.** A `\sqrt{a}` inserts a `*` after a letter, a digit, or
  a `)`, the same as `√` does, so `5x\sqrt{2}` is `5*x*sqrt(2)` and no longer the name
  `xsqrt` (finding #9).
- **A space-grouped number is a whole operand.** `1 000` is accepted as the whole answer or
  as a full operand at the top level, and after any factor it is undecidable. `x/1 000` no
  longer reads as `x/1 * 0` (finding #11).
- **The times-`x` reading takes a negated literal.** `-2.5 x 10^-4` is -0.00025, and
  `-1617x` no longer accepts `-3 x 539` (finding #12).

### The canonical form (FIXM2e)

- **`Atom::E` folding.** The whole-number part of an `Atom::Exp` argument folds into
  `Atom::E`, so `e^(x+2)`, `e^2*e^x`, and `e^x*e^2` are one value, and `e^(x+2)` and
  `e^(x+3)` are two values (finding #8).
- **One `Inverse` per monomial.** A monomial holds at most one `Atom::Inverse`, with
  exponent 1. `Inverse(p)^n` is `Inverse(p^n)` and two `Inverse` atoms merge into
  `Inverse(p*q)`, so `(1/(x+1))^2` is `1/(x+1)^2` and `4/(x-2) * 1/(x+2)` is
  `4/((x-2)(x+2))`. The rule cancels no common factor: `(x^2-1)/(x-1)` and `x+1` stay two
  values (findings #13, #17).

### The oracle harness (FIXM2e, FIXM2f)

- **No catch-all reason.** A pair leaves class 3 only when a predicate names the 1.0 line
  it ports. The `names_a_transcendental` substring test is deleted: it excused five
  `cos 2*x` parse divergences that hold no identity, and the parity report claimed 100%
  agreement while five recorded 1.0 verdicts disagreed (findings #10, #14). The float rung
  predicate is specific in the same way: it reads both values and asks whether the gap is
  inside the 1e-9 or the 1e-6 tolerance that 1.0 applies, so a wrong number keeps no reason
  and stays in class 3.
- **The five missing generator families.** The harness runs every family that spec section
  9.3 names, except "word anagram": that family applies to prose, and prose leaves the 2.0
  grammar, so every anagram pair is class 1 and it measures nothing. `answer_divergence.rs`
  pins the 1.0 anagram defect instead. FIXM2e added "internal space collapse". FIXM2f added
  the last four: case flip
  (`SQRT(2)`, decided on the casefolded string rung of both checkers), decimal to at least
  8 significant digits (a documented D6 divergence: 1.0 True on its float rung, 2.0 False),
  commutative reorder of a product (`x*2` for `2*x`), and algebraic refactor (`(x-1)*(x+1)`
  for `x**2-1`, and the multiplied-out form of a factored corpus answer). Every generator
  is deterministic and seeded, the 20,000-pair cap stands, and the harness names every pair
  the cap drops (finding #16).

Measured after the fixes: the corpus split does not move — 3,492 answers, 3,227 parsed and
265 undecidable, and the committed `undecidable_1_0.jsonl` is unchanged. The generated
oracle set grew from 14,989 to 17,047 pairs. Class 1 holds 931 pairs, class 3 holds 15,940,
and class 4 holds 176. Class 3 agreement with the live 1.0 checker is 15,940 of 15,940
(100.0000%), and no pair of the set carries an undocumented divergence.
